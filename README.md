## 📌 Project Overview
This is a desktop-based application developed in **Java** utilizing **Swing (GUI)** components. It serves as an administrative control dashboard for hospital workflows including login authentication, doctor profiling, tracking appointment logs, scheduling data structures, and monitoring operational capacities.

## 🛠️ Concepts & Features Implemented
* **Graphical User Interface (GUI):** Built dynamic windows, grids (`GridLayout`), action inputs, and interactive popups using Java Swing components (`JFrame`, `JButton`, `JOptionPane`, `JTextArea`).
* **Object-Oriented Programming (OOP):** Applied standard encapsulation, clean inheritance hierarchies (`Hospital extends User`), and modular data constructors.
* **Security & Authentication:** Configured a secure administrator multi-attempt credential lock mechanism to protect backend system routes.
* **Data Structures:** Managed dynamic patient queues and staffing records concurrently using Java `ArrayList` collections and associative `HashMap` key pairing mappings.
